## 调用参数

- **来源**: [TKI_003].response.data.taskId
- **格式**: JSON Payload / Long
- **说明**: 引用上传接口生成的任务 ID。

## 返回结果

### 结构说明
| 字段路径 | 类型 | 说明 |
|---------|------|------|
| code | Integer | 响应码（0=成功） |
| success | Boolean | 业务处理是否成功 |
| message | String | 响应消息 |
| data | Boolean | 取消结果（true=成功） |

### 数据保存
- **[TKD_001] (数据清理)**: 执行成功后，数据库表 `dataops_batch_operation_task` 中对应 `taskId` 的记录将被删除。

### 关键知识
- **任务清理机制**: 该接口用于在批量入仓任务正式生效（发布）前进行撤回。调用后，后端系统会清理该任务在 `dataops_batch_operation_task` 中的相关数据。
- **验证判定标准**: 取消是否成功的核心判定指标是数据库表 `dataops_batch_operation_task` 中对应 `taskId` 的记录数量。若 `COUNT(*)` 等于 0，则判定为彻底取消。
- **操作时序要求**: 通常用于“校验失败”或“提交前”的场景。若任务已进入 BPM 审批流并生成工单，需额外关注流程记录的同步清理状态。
- **API交互规范**: 注意该接口的参数是通过 Request Body (JSON Payload) 传递，而非 Path 参数或 Query 参数。
