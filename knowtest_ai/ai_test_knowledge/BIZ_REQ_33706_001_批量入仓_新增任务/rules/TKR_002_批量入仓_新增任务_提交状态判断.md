# 批量操作任务提交审批状态判断

## 规则说明

判断调用提交批量操作任务接口后，系统是否成功发起审批流。需同时满足以下两个条件：
1. **BPM记录生成**：在 `dataops_bpm_record`  中产生关联记录，状态为审批中（status=2），且业务类型匹配。
2. **作业状态联动**：`dataops_batch_operation_task` 的任务状态更新为“待审核”，且成功反填 BPM 工单号。

**判断依据**: 
- dataops_bpm_record.process_instance_node_id = 提交批量操作任务接口路径参数 `{taskId}`
- dataops_bpm_record.process_key = 'bg_jdbc_rc_plxz_rw'
- dataops_bpm_record.status = 2
- dataops_batch_operation_task.task_status = 'PENDING_APPROVAL'
- dataops_batch_operation_task.bpm_order_no = dataops_bpm_record.order_no


---

## 验证方法

```yaml
# 验证批量任务已进入审批工作流
- field_equals:
    table: "dataops.dataops_batch_operation_task"
    field: "task_status"
    where: "id='${taskId}' AND bpm_order_no IS NOT NULL"
    expected: "PENDING_APPROVAL"

# 验证BPM审批记录已正确创建
- field_equals:
    table: "dataops.dataops_bpm_record"
    field: "status"
    where: "process_instance_node_id='${taskId}' AND process_key='bg_jdbc_rc_plxz_rw'"
    expected: "2"
```

**SQL查询**:
```sql
SELECT 
    t1.task_status, 
    t1.bpm_order_no, 
    t2.order_no AS bpm_record_no,
    t2.status AS bpm_status
FROM dataops.dataops_batch_operation_task t1
INNER JOIN dataops.dataops_bpm_record t2 
    ON t1.id = t2.process_instance_node_id
WHERE t1.id = '${taskId}' 
  AND t2.process_key = 'bg_jdbc_rc_plxz_rw'
  AND t1.bpm_order_no = t2.order_no;
```

**预期结果**: 
- `task_status = 'PENDING_APPROVAL'`
- `bpm_status = 2`
- `bpm_order_no` 与 `bpm_record_no` 一致且不为空。

```yaml
# 1. 准备批量作业原始数据
dataops.dataops_batch_operation_task:

    task_status: "PENDING_APPROVAL"
    bpm_order_no: "BPM_ORDER_20240522001"
    task_type: "BATCH_ADD_TASK"

# 2. 准备对应的BPM审批记录
dataops.dataops_bpm_record:
  - id: 1001
    order_no: "BPM_ORDER_20240522001"
    process_instance_node_id: "385"
    process_key: "bg_jdbc_rc_plxz_rw"
    status: 2
```
