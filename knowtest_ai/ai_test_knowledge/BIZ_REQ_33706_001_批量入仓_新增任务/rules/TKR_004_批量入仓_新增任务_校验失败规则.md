# 批量入仓上传校验失败中断判断

## 规则说明

当用户上传批量操作文件后，系统会进行异步校验。若文件格式、内容或业务规则不符合要求，任务状态将变更为“校验失败”。此时，流程应在提交阶段前中断，不允许进入后续的审批环节。

**判断依据**: 
- `dataops_batch_operation_task`的 `id` 等于 `{taskId}`。
- **校验标准**：`task_status` 为 `VALIDATE_FAILED`。

---

## 验证方法

```yaml
# 验证批量上传任务校验失败
- field_equals:
    table: "dataops.dataops_batch_operation_task"
    field: "task_status"
    where: "id='${taskId}' AND task_type='UPLOAD'"
    expected: "VALIDATE_FAILED"
```

**SQL查询**:
```sql
SELECT task_status, error_message
FROM dataops.dataops_batch_operation_task
WHERE id = '${taskId}'
  AND task_type = 'UPLOAD';
```

**预期结果**: 
- `task_status = 'VALIDATE_FAILED'`

---

## 测试数据准备

```yaml
# 准备上传校验失败的数据
dataops.dataops_batch_operation_task:
  - id: 388
    task_type: "UPLOAD"
    task_status: "VALIDATE_FAILED"
    error_message: "{\"error\": \"Column 'user_id' not found\"}"
    created_by: "test_user"
```
