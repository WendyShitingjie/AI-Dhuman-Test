# BPM审批回调及任务执行状态判断

## 规则说明

判断在BPM审批通过并回调（或发出MQ消息）后，DataOps系统是否成功消费并进入任务发布/执行阶段。

**判断依据**: 
1. **BPM记录状态更新**：`dataops_bpm_record`  的状态变更为已通过（status='4'）。
2. **作业执行状态联动**：`dataops_batch_operation_task` 的任务状态变更为“执行中”（EXECUTING）。
   - *注：若任务量极小，状态可能在毫秒级内从 EXECUTING 变为 SUCCESS，校验时需兼容这两种终态。*

---

## 验证方法

```yaml
# 1. 验证BPM审批记录已更新为“审批通过”
- field_equals:
    table: "dataops.dataops_bpm_record"
    field: "status"
    where: "process_instance_node_id='${taskId}' AND process_key='bg_jdbc_rc_plxz_rw'"
    expected: "4"

# 2. 验证批量作业已进入“执行中”或“已完成”状态
- field_in:
    table: "dataops.dataops_batch_operation_task"
    field: "task_status"
    where: "id='${taskId}'"
    expected: ["EXECUTING", "SUCCESS"]
```

**SQL查询**:
```sql
SELECT 
    t2.status AS bpm_status,
    t1.task_status AS task_status
FROM dataops.dataops_batch_operation_task t1
JOIN dataops.dataops_bpm_record t2 
    ON t1.id = t2.process_instance_node_id
WHERE t1.id = '${taskId}'
  AND t2.process_key = 'bg_jdbc_rc_plxz_rw';
```

**预期结果**: 
- `bpm_status = '4'`
- `task_status` 为 `EXECUTING`（执行中）或 `SUCCESS`（执行成功）。

---

## 测试数据准备

```yaml
# 1. 准备BPM审批通过数据
dataops.dataops_bpm_record:
  - process_instance_node_id: "385"
    process_key: "bg_jdbc_rc_plxz_rw"
    status: "4"  # 审批通过

# 2. 准备作业执行状态数据
dataops.dataops_batch_operation_task:
  - id: 385
    task_status: "EXECUTING"  # 或 SUCCESS
    updated_at: "2024-05-22 10:00:01"
```
