# 批量上传校验状态判断

## 规则说明

判断调用批量上传校验接口后，对应的后台异步作业是否校验成功并进入待处理状态。

**判断依据**: 
1. `id` 匹配接口返回的 `taskId`。
2. `task_status` 为 `VALIDATE_SUCCESS`（校验成功）。
3. `task_type` 为 `UPLOAD`（上传类型）。

---

## 验证方法

```yaml
# 验证批量上传作业已校验成功
- field_equals:
    table: "dataops_batch_operation_task"
    field: "task_status"
    where: "id='${taskId}' AND task_type='UPLOAD'"
    expected: "VALIDATE_SUCCESS"
```

**SQL查询**:
```sql
SELECT task_status, task_type
FROM dataops_batch_operation_task
WHERE id = '${taskId}' 
  AND task_type = 'UPLOAD';
```

**预期结果**: 
- `task_status = 'VALIDATE_SUCCESS'`
- `task_type = 'UPLOAD'`
