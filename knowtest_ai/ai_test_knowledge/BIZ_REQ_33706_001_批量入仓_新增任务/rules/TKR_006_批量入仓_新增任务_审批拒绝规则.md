# 批量入仓审批拒绝流程中断判断

## 规则说明

在批量入仓任务进入审批流后，若审批人员执行“拒绝”操作，系统需确保：
1. **BPM记录状态** 更新为已拒绝（status=3）。
2. **作业任务状态** 同步更新为审批失败（APPROVING_FAIL）。

本规则用于验证双表在审批拒绝场景下的状态一致性。

**判断依据**: 
- **关联条件**：`dataops_batch_operation_task.id = dataops_bpm_record.process_instance_node_id` 且 `dataops_batch_operation_task.bpm_order_no = dataops_bpm_record.order_no`。
- **业务约束**：`dataops_batch_operation_task.process_key = 'bg_jdbc_rc_plxz_rw'`。
- **校验标准**：
  - `dataops_batch_operation_task.task_status = 'APPROVING_FAIL'`
  - `dataops_bpm_record.status = 3`

---

## 验证方法

```yaml
# 1. 验证批量作业状态为“审批失败”
- field_equals:
    table: "dataops.dataops_batch_operation_task"
    field: "task_status"
    where: "id='${taskId}'"
    expected: "APPROVING_FAIL"

# 2. 验证BPM审批记录为“已拒绝”
- field_equals:
    table: "dataops.dataops_bpm_record"
    field: "status"
    where: "process_instance_node_id='${taskId}' AND process_key='bg_jdbc_rc_plxz_rw'"
    expected: "3"
```

**SQL查询**:
```sql
SELECT 
    t1.task_status, 
    t1.bpm_order_no, 
    t2.status AS bpm_status
FROM dataops.dataops_batch_operation_task t1
INNER JOIN dataops.dataops_bpm_record t2 
    ON t1.id = t2.process_instance_node_id 
    AND t1.bpm_order_no = t2.order_no
WHERE t1.id = '${taskId}'
  AND t2.process_key = 'bg_jdbc_rc_plxz_rw';
```

**预期结果**: 
- `task_status = 'APPROVING_FAIL'`
- `bpm_status = 3`

```yaml
# 1. 准备批量作业拒绝状态数据

    process_key: "bg_jdbc_rc_plxz_rw"
    status: 3  # 审批拒绝
```
